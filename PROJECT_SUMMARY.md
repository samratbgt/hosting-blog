## 🚀 **Getting Started**

1. **Install Dependencies**
   ```bash
   cd hosting-blog
   npm install
   ```

2. **Run Setup Script** (Optional)
   ```bash
   npm run setup
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Open Browser**
   Navigate to http://localhost:3000
